# Java Study


## 운영 정보

- 운영 기간: 2026.09.14 ~ 2026.12.22
- 운영 횟수: 총 15주
- 학습 분야: Java 프로그래밍
- 진행 방식: 개별 학습 + GitHub 기록 + 주 1회 질의응답
- 문제 풀이: 프로그래머스, 백준 등을 활용한 Java 문제 풀이
- 활동 방식: 대면·비대면 병행
- 주요 활동 장소: 학교 중앙도서관 또는 소프트웨어학부 학회실

---

## 운영 목표

- Java의 주요 문법과 객체지향 프로그래밍 개념을 단계적으로 학습한다.
- 매주 직접 코드를 작성하고 문제를 해결하며 프로그래밍 문제 해결 능력을 기른다.
- 학습한 개념과 문제 풀이 과정을 GitHub에 꾸준히 기록한다.
- 서로의 코드와 풀이 방법을 비교하며 다양한 문제 해결 방식을 익힌다.
- 정기적인 질의응답과 코드 리뷰를 통해 부족한 개념을 보완한다.
- 중간·후반·최종 점검을 통해 이전 학습 내용을 반복적으로 복습한다.

---

## 운영 방식

1. 매주 정해진 Java 학습 범위를 공부한다.
2. 학습한 개념을 정리하고 관련 예제 코드를 작성한다.
3. 매주 학습 주제와 관련된 코딩 문제를 최소 2~3문제 이상 풀이한다.
4. 개념 정리, 예제 코드, 문제 풀이를 GitHub에 업로드한다.
5. 문제 풀이 시 정답 코드만 기록하지 않고 문제 접근 방법과 새롭게 알게 된 내용을 함께 정리한다.
6. 매주 대면 또는 비대면 모임을 1회 진행한다.
7. 모임 전까지 학습 과정에서 이해하지 못한 내용이나 질문을 미리 정리한다.
8. 모임에서는 질문 공유 → 서로의 풀이 비교 → 해결 방법 정리 순서로 진행한다.
9. 서로 다른 풀이가 나온 경우 코드의 차이와 장단점을 비교한다.
10. 중간·후반·최종 점검을 통해 이전 학습 내용을 복습하고 부족한 부분을 보완한다.
11. 마지막 주에는 전체 학습 내용을 복습하고 GitHub 기록을 최종 정리한다.
